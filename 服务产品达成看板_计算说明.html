二、周期口径

  • 服务月：通用规则 = 上月 28 日 → 当月 27 日。
    特例：1 月 = 25.12.28–26.1.27；2 月 = 26.1.28–2.25；3 月 = 2.26–3.27；4 月 = 3.28–4.27。
    当前 9 月 = 2026.8.28 – 9.27（31 天）。
  • 服务年：2025.12.28 – 2026.12.27。
  • 统计截止日 = 更新日 − 1（D−1 铁律）；若未通知更新，则冻结在上一次截止日、不自动滚动。
  • 时间进度 = 已过天数 ÷ 服务月总天数。例：9/14 → 18 ÷ 31 = 58.06%。

三、目标口径

  • 整体目标 = 15 个品项的目标合计。
  • 三大爆品 = 清洗保养 + 延保服务 + 清洁耗材（三类合并为 1 个数）。
  • 办事处年目标（合计 ¥495 万）：新疆 187 / 宁夏 124 / 兰州 93 / 包头 39 / 呼和浩特 36 / 西宁 16（单位：万元）。
  • 达成率 = 实际 ÷ 目标；120% 目标 = 目标 × 1.2。

四、各模块计算逻辑

1. 整体达成（办事处 · 网点明细）

实际合计 = 服务产品收入统计各网点 × 品项金额合计（按【数据来源】列「合计」求和）
达成率 = 实际合计 ÷ 整体目标

2. 三大爆品

实际 = 清洗保养 + 延保服务 + 清洁耗材 三项实际合计
达成率 = 实际 ÷ 三大爆品合并目标

3. 工单 / 服务量

  • 工单数 = 工单明细行数（服务完成时间落在服务月周期内）。
  • 支持按 办事处 / 产品组 / 服务项目 / 工单类型 分组查看。

4. 防火阀（止回阀）占比

止回阀数量 = CSM配件表中「销售分类 = 止回阀」且「上缴金额 > 0」的 数量(S列)之和
　（仅统计服务月周期内工单对应的止回阀；金额为 0 / 空 / 非数字一律剔除）
烟机安装量 = 工单表中「产品组 = 吸油烟机」且「服务项目 ∈ {安装, 改装, 油烟机预埋烟管}」的工单量
防火阀占比 = 止回阀数量 ÷ 烟机安装量 × 100%
⚠️ 易错点：止回阀是取 数量列(S)求和，不是行数计数。支持 办事处 / 网点 / 工程师 三维度查看。
本次版本校验：止回阀数量在 工单（防火阀占比）、增值产品、增值配件 三个模块须完全一致（9 月 = 833）。

5. 增值产品

  • 源：CSM配件表 + 工单自购配件明细。
  • 日期过滤以 「录入完成时间」 为准（CSM配件 AK 列 / 自购 K 列）——注意与工单模块用「服务完成时间」不同。
  • 各品项计数；其中 止回阀 走特殊口径（同上第 4 条）。
  • 全区总计数 = 各品项计数之和。

6. 增值配件（时间窗口）

  • 窗口：昨日 / 近 3 日 / 近 7 日 / 当月（以统计截止日为基准回算）。
  • 各品项计数 + 覆盖工程师数。

7. 大保养占比

分母 = 销售分类 = 清洗保养 的行数，剔除「保养超范围收费」「灶具保养」
分子 = 「油烟机大保养」+「油烟机大保养升级包」单数（只计单量，与金额无关）
占比 = 分子 ÷ 分母

8. 延保服务

  • 源：CSM服务项目表，销售分类 = 延保服务。
  • 按「服务收费项目」拆年限：含"一年"→ y1、含"两年"→ y2、含"三年"→ y3。
  • 按「录入完成时间」落在服务月周期内。
  • 指标：单数 + 上缴金额合计；时间窗口：昨日 / 近 3 日 / 近 7 日（以统计截止日为 cut）。

9. 清洗保养

  • 源：CSM服务项目表，销售分类 = 清洗保养。每行 = 1 单；数量 = 行数；金额 = 上缴金额(Y列)。
  • 免费单 = 上缴金额 = 0；收费单 = 上缴金额 > 0。
  • 免费/收费统计仅含主保养四项：油烟机小保养、油烟机大保养、集成灶小保养、集成灶大保养（其余如"保养超范围收费""灶具保养"不计）。
  • 维度：办事处 / 服务网点 / 服务工程师（各维度带合计行）。
  • 主项选择器：全部 / 4 个单项（选单项时明细表只显示数量列）。

10. 下钻（办事处 → 网点）· 目标差值 KPI

距离 100% 差值 = 目标 × 1.0 − 实际
距离 110% 差值 = 目标 × 1.1 − 实际
完成 120% 差值 = 目标 × 1.2 − 实际
剩余每天需完成 = 差值 ÷ 剩余天数（剩余天数 = 服务月天数 − 已过天数）
日均完成金额 = 实际 ÷ 已过天数
  • 当差值 ≤ 0 时显示「已达成」。
  • 着色：按该档达成率（实际 ÷ 目标×档位）呈「近绿远红」渐变（越接近该档目标越绿，越远越红）；已达成固定为绿色。

11. 年度累计视图

  • 1–N 月各月数据合并展示；统计截止日取各月中的最大值。
  • 年度目标进度按服务年（12.28–12.27）计算时间进度，与月度进度相互独立。

五、调平约定

【数据来源】列中的「网点买断」与「调整（虚拟网点 / 虚拟技师）」原样计入——按「合计」列求和，表里写什么就显示什么，不做剔除。

六、配色约定

  • 涨红跌绿：红色 = 增长/达成，绿色 = 下降（中国习惯）。
  • 目标差值卡：离目标越近越绿、越远越红（HSL 由红到绿渐变）。

七、更新与同步

  • 统计截止日 = 更新日 − 1，未通知更新则冻结、不自动滚动。
  • 每次数据更新后版本号（BUILD）变化；用在线链接查看时需按 Ctrl+Shift+R 硬刷新。
  • 离线使用：直接用新版 dashboard.html 覆盖旧文件即完成同步，无需联网。
