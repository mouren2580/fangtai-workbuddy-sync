### 环境踩坑（重要）
- 本会话 PowerShell 工具的 stdout **不回显**，必须把结果 `Set-Content` 写文件再用 Read 读。
- `Get-ChildItem C:\Windows -Recurse` 会导致 PowerShell 脚本直接终止（exit 1），统计磁盘时要避开 C:\Windows。
- 写 `C:\Users\40973\Desktop` 会被沙箱拦截，需 `dangerouslyDisableSandbox: true`。
- Bash 里禁止调用 `cmd.exe`；PowerShell 里含 `>nul` 字面量的字符串会被安全策略拦截。
- bat 文件必须存为 **GBK(936)**，否则中文乱码。冒烟测试法：python 改写副本 → 把路径重定向到工作区 → PowerShell 直接 `& "xxx.bat"` 执行。

## 脚本 v2 修订（用户反馈"双击一闪而过"）

原因定位：桌面无 `WorkBuddy_优化日志.txt` → 脚本在 **UAC 提权分支就退出了**，从未到菜单。
已排除的可能：`Start-Process` 对中文路径正常、`%~f0` 解析正常（实测 `测试_中文路径.bat` 通过）。

v2 改动：
1. 日志改为 `%~dp0WorkBuddy_运行日志.txt`，**第一行就写**（提权检查之前），便于定位卡在哪。
2. 权限判断 `fltmc` → `net session`。
3. 提权前 `cls` + 大字提示"请看屏幕中间的用户账户控制窗口点【是】"，并给出右键→以管理员身份运行的兜底说明。
4. `Start-Process` 加 `-LiteralPath` 与 `-ErrorAction Stop`，失败时 `2>>日志` 且窗口 **pause 不关闭**。
5. 加 `cd /d "%~dp0"`（提权后默认落在 System32）。
6. 清理步骤移除了 `taskkill explorer.exe`（有风险，会把桌面外壳杀掉）。
7. 各耗时步骤加"进度条不动是正常"的提示。

经验：Windows bat 交付给用户时，**任何静默 exit 都会被当成"闪退"**，必须在退出前把原因打出来并 pause。
