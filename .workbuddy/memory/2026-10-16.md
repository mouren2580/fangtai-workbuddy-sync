## 本轮踩坑
1. **误判 git 提交失败**：`git add -A && git commit -q …&& git push` 输出「nothing to commit, working tree clean」，看着像提交失败，实际 **commit 已成功**（HEAD `5f04226`），只是 `&&` 短路导致 push 没跑。
   → 判断依据永远是 `git log -1` / `git rev-parse --short HEAD`，别信 commit 回显；push 与 commit **分开写命令**。
2. **`git rev-parse HEAD origin/main github/main` 报 `fatal: Needed a single revision`**：远端跟踪分支不存在时会连带让整条命令失败，别把多个 ref 塞进一条 rev-parse。
