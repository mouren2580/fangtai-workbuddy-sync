## 本次新增踩坑（已同步进 skill）
1. **系统 python 没有 openpyxl**：`binaries/python/versions/3.13.12/python.exe` 跑 `build_month.py` 会 `ModuleNotFoundError`。
   必须用 venv：`C:/Users/40973/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（openpyxl 3.1.5）。
2. **`push_gh_pages.py` 不要后台运行**：以 `run_in_background` 方式跑会卡死——SSH 在后台环境被挂起，25 分钟无任何输出、克隆目录文件都没被覆盖。
   → 必须**前台 + 沙箱旁路**执行；若已卡住用 TaskStop 杀掉，改手动推。
3. **手动推 Pages 仓库时路径必须用 Windows 形式**：`git -C "/c/Users/.../tmp/fangtai-dashboard"` 会报
   `fatal: cannot change to '...': No such file or directory`（git.exe 不认 MSYS `/c/` 路径），
   要写 `git -C "C:/Users/40973/.workbuddy/tmp/fangtai-dashboard"`。
4. **工具重放会造成假输出**：`git add -A && git commit && push` 这种长链，返回的可能是重放那一遍的输出（显示
   `nothing to commit, working tree clean`），但**第一次执行其实已经 commit 成功**。
   → 判定标准：看 `git log --oneline -1` 与 `git log origin/main..HEAD`，不要被 "nothing to commit" 误导而重复提交。
